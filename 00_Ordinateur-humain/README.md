# 00 · L'ordinateur humain

> ⏱ 25 min · En binôme · IA niveau 0 · Jour 1 matin

**Ne montre pas ce dossier au pilote : c'est lui qui va jouer la machine.**

1. Avec ton binôme, ouvre l'image de ton dessin secret : `dessin-A.png` si votre numéro de binôme est impair, `dessin-B.png` s'il est pair.
2. Dans un fichier `instructions.txt`, écrivez les instructions qui permettent de **reproduire exactement ce dessin**, sans le voir. ⏱ 10 min
3. Le pilote va exécuter vos instructions au tableau, **à la lettre**, sans rien deviner. Il ne voit pas le dessin.
4. Comparez le résultat avec le modèle : quelles instructions ont posé problème ?

Le piège : « à droite », mais de quoi ? « Un grand rond », de quelle taille ? Une machine a besoin de **dimensions**, d'un **repère** et d'un **ordre**.
