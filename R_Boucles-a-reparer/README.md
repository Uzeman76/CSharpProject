# R · Les boucles à réparer

> ⏱ 25 min · En binôme · IA niveau 0 · Jour 2 matin

Quatre boucles cassées, une par dossier. Pour chacune, dans cet ordre :

1. **Lis le code et écris ta prédiction** en commentaire : que va-t-il afficher ?
2. Exécute : `cd R1` puis `dotnet run`. Si le programme ne s'arrête pas : `Ctrl+C`.
3. Compare avec ta prédiction : où ton raisonnement a-t-il divergé ?
4. Corrige, et vérifie que tu obtiens le résultat attendu, écrit en haut du fichier.

Prédire avant d'exécuter, c'est l'entraînement le plus utile du module : c'est ce que tu fais quand tu relis le code d'un autre, ou celui d'une IA.

## Défi
Pour R4 : réécris la condition avec `!` (NON) et un seul `||` (OU). Les deux versions sont-elles équivalentes ?
